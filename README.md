# Bilingual Sentence Alignment Tool
This is a Python script for MTI translation study. It aligns English source text and Chinese translation sentence by sentence, and exports results to Excel.

## Features
- Read source text and target translation from two txt files
- Align sentences line by line
- Generate Excel table with bilingual parallel text

## Requirements
Python 3.8+
pandas
openpyxl
